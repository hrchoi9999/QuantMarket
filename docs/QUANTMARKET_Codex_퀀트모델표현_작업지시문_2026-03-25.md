# QUANTMARKET_Codex_퀀트모델표현_작업지시문_2026-03-25.md

## 목적
QuantMarket 화면과 데이터 설명 전반이 "시장분석 서비스"처럼만 보이지 않고, REDBOT의 핵심이 **시장 상황을 읽어 주간 브리핑용 퀀트투자 모델 해석에 연결해 주는 시스템**임을 드러내도록 정리한다.

이번 작업은 시장 브리핑 페이지가 아래 4개 표현과 자연스럽게 연결되도록 만드는 것이 핵심이다.

- 멀티애셋 데이터 기반 퀀트투자 모델
- 공개 기준 기반 퀀트투자 모델
- 주간 브리핑용 퀀트투자 모델
- 모델 포트폴리오를 산출하는 퀀트투자 모델

---

## 현재 문제 인식
현재 시장 브리핑 페이지는 시장상태 자체는 잘 설명하지만, 사용자가 보기에 이것이 REDBOT의 퀀트투자 모델과 어떻게 연결되는지 전달력이 약하다.

특히 아래 표현은 서비스 정체성을 흐린다.

- `시장분석`
- `대응 가이드`
- `스냅샷 기반 퀀트 투자 브리핑 서비스`
- `시장 상태와 점수`
- `시장 방향 / 시장 건강도 / 시장 흔들림`만 있고 모델 연결 설명이 약함

즉, QuantMarket이 단독 페이지처럼 보이고, 퀀트투자 모델과의 연결이 약하다.

---

## 작업 목표
1. 시장 브리핑 페이지가 "시장 데이터 설명"에서 끝나지 않고 "퀀트투자 모델 해석 기반" 페이지로 보이게 만든다.
2. `대응` 중심 표현을 `모델 해석`, `모델 참고`, `브리핑 포인트` 중심으로 바꾼다.
3. QuantMarket이 QuantService/Quant와 연결된 구조임을 더 명확히 보여준다.
4. 사용자에게 "이 서비스는 다양한 시장 데이터 기반의 상황별 퀀트투자 모델 정보 서비스"라는 인식을 강화한다.

---

## P0 작업

### 1) 상단 서비스 정의 문구 교체
현재:
- 스냅샷 기반 퀀트 투자 브리핑 서비스

교체:
- 다양한 시장 데이터 기반의 상황별 퀀트투자 모델 정보 서비스
또는
- 멀티애셋 데이터 기반 퀀트투자 모델 정보 서비스

권장안:
- `다양한 시장 데이터 기반의 상황별 퀀트투자 모델 정보 서비스`

### 2) 메뉴명 교체
현재:
- 시장분석
- 오늘의 추천
- 성과

교체:
- 시장 브리핑
- 이번 주 모델 기준안
- 성과 설명

QuantMarket 페이지 내부와 상단/하단 네비게이션 모두 동일 적용.

### 3) 페이지 제목 교체
현재:
- 시장분석

교체 후보:
- 시장 브리핑
- 퀀트투자 모델 시장 브리핑
- 주간 모델 브리핑

권장안:
- `시장 브리핑`

부제:
- `퀀트투자 모델 해석에 필요한 시장 상태를 같은 기준으로 정리합니다.`

### 4) 핵심 설명문 재작성
현재:
- 지수는 우호적이지만 내부 확산이 더 확인되면 좋겠습니다.
- QuantMarket이 생성한 최신 handoff 데이터를 그대로 사용합니다.
- 수치는 재계산하지 않고, QuantService는 읽기 쉬운 화면으로만 정리합니다.

바꿀 방향:
- QuantMarket은 다양한 시장 데이터를 바탕으로 주간 브리핑용 퀀트투자 모델 해석에 필요한 시장 상태를 생성합니다.
- 이 페이지의 시장 상태 정보는 공개 기준 기반 퀀트투자 모델의 참고 지표로 사용됩니다.
- QuantService는 QuantMarket이 생성한 브리핑 데이터를 사용자에게 읽기 쉬운 모델 설명 화면으로 제공합니다.

### 5) `대응 가이드` 섹션명 교체
현재:
- 대응 가이드

교체:
- 모델 참고 포인트
또는
- 이번 주 모델 해석 포인트

권장안:
- `이번 주 모델 해석 포인트`

설명도 아래처럼 수정:
- `현재 시장 상태를 기준으로 퀀트투자 모델을 읽을 때 참고할 핵심 포인트입니다.`

### 6) `추천 대응 톤` 표현 삭제
오늘 페이지와 연결되는 QuantMarket 데이터에 `추천 대응 톤` 같은 필드를 넘기지 않는다.

교체:
- `모델 참고 톤`
- `브리핑 톤`
- `시장 해석 톤`

권장안:
- `브리핑 톤`

## P1 작업

### 7) 지표 블록 이름을 모델 해석 중심으로 재정리
현재:
- 시장 방향
- 시장 건강도
- 시장 흔들림
- 방어자산 선호도

바꿀 수 있는 후보:
- 시장 추세 점검
- 시장 확산 점검
- 변동성 점검
- 방어자산 선호 점검

권장안:
- `시장 추세 점검`
- `시장 확산 점검`
- `시장 변동성 점검`
- `방어자산 선호 점검`

이유:
- 사용자에게 더 직관적이고,
- 점검 결과가 곧 모델 해석 근거라는 점을 전달하기 좋다.

### 8) 긍정 신호 / 주의 신호를 모델 연결형으로 조정
현재:
- 긍정 신호
- 주의 신호

교체:
- 모델에 우호적인 신호
- 모델 해석상 주의할 신호

권장안:
- `모델에 우호적인 신호`
- `모델 해석상 주의할 신호`

### 9) 하단 데이터 출처 설명 보강
현재:
- 생성 주체 QuantMarket
- 표시 주체 QuantService

추가:
- `이 데이터는 주간 브리핑용 퀀트투자 모델 해석을 위한 공개 브리핑 데이터입니다.`
- `시장 상태 자체를 설명하는 동시에 모델 포트폴리오 변화의 배경 정보를 제공합니다.`

## P2 작업

### 10) 시장 브리핑과 모델 기준안 연결 모듈 추가
페이지 중간 또는 하단에 작은 연결 카드 추가:

제목:
- `이 시장 브리핑은 어디에 쓰이나요?`

본문:
- `이 브리핑은 멀티애셋 데이터 기반 퀀트투자 모델을 해석하기 위한 공개 기준 데이터입니다.`
- `이번 주 모델 기준안과 변경내역은 이 시장 상태를 참고해 함께 읽을 수 있습니다.`

버튼:
- `이번 주 모델 기준안 보기`
- `변경내역 보기`

### 11) QuantMarket 용어 사전 추가
아래 표현을 공통 사전으로 강제한다.

- market_analysis → market_briefing
- response_guide → model_reference_points
- recommendation_tone → briefing_tone
- state_summary → market_brief_summary
- signal_positive → model_favorable_signals
- signal_caution → model_caution_signals

## 개발 완료 조건
1. QuantMarket 페이지가 시장 설명 페이지가 아니라 퀀트투자 모델 브리핑 페이지로 읽혀야 한다.
2. `대응`, `추천` 계열 용어가 제거되어야 한다.
3. 시장 상태와 모델 기준안의 연결이 사용자가 이해 가능한 수준으로 명확해야 한다.
4. 모든 표식과 제목이 서비스 전체 용어 체계와 맞아야 한다.
