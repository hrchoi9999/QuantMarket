# QS-Master 작업요청서

- QS 요청 제출처: QS-Master
- 권장 담당 쓰레드: QS-Public-Web, QS-QM-Handoff
- 공개 반영 포함 여부: Yes
- Admin only 여부: No
- 관련 시스템: QuantMarket

## 작업명

시장 브리핑 `시장 분위기` 블록 4문장 x 2구역 표시 반영 요청

## 배경

QuantMarket의 Gemini 기반 `시장 분위기` 브리핑 생성 기준을 수정했습니다.
기존에는 긍정 요인 3문장, 리스크 요인 3문장 총 6줄이었으나,
시니어 투자자가 시장 분위기를 더 직관적으로 이해할 수 있도록
긍정 요인 4문장, 리스크 요인 4문장 총 8줄로 확대합니다.

문장도 추상적인 표현을 줄이고, 지수/환율/수급/선물/종목 확산/뉴스 등 구체 근거를 포함하도록 조정했습니다.

## 대상 payload

- `quantservice_market_page.json`
- `api_v1_market_analysis_page.json`
- `quantservice_market_home.json` 중 시장 분위기 축약 표시가 있다면 함께 확인

## 변경된 데이터 계약

`ai_briefs.providers[]` 중 `provider="gemini"` 항목의 `summary_lines`가 최대 8줄로 제공됩니다.

- `summary_lines[0:4]`: 긍정적 요인
- `summary_lines[4:8]`: 리스크 요인

각 줄은 아래 prefix를 유지할 수 있습니다.

- `긍정:`
- `리스크:`

QS 표시 시에는 기존처럼 prefix를 제거하고 본문만 보여줘도 됩니다.

## UI 반영 요청

1. `시장 분위기` 블록을 기존 3줄 + 3줄 기준에서 4줄 + 4줄 기준으로 변경해 주세요.
2. `긍정적 요인` 소블록에는 `summary_lines[0:4]`를 표시해 주세요.
3. `리스크 요인` 소블록에는 `summary_lines[4:8]`를 표시해 주세요.
4. payload가 아직 6줄만 내려오는 경우에는 기존 3+3 또는 가용 줄 수 기준으로 fallback 처리해 주세요.
5. 문장이 조금 길어졌으므로 모바일에서는 줄간격과 카드 높이가 자연스럽게 늘어나도록 처리해 주세요.

## 완료 기준

1. 공개 시장 브리핑 페이지에서 긍정 요인 4개, 리스크 요인 4개가 보입니다.
2. 6줄 구버전 payload도 깨지지 않습니다.
3. 홈/오늘의 추천 등 축약 표시 영역은 필요 시 첫 1~2줄만 사용하되, 전체 시장 브리핑 페이지는 8줄을 표시합니다.
4. 투자자문처럼 보이는 버튼/행동 지침 문구는 추가하지 않습니다.
